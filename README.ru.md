# Teekas Studio

[English](README.md) | **Русский**

Локальный 2D-аватар для стримеров. Персонаж живёт в OBS как прозрачный браузерный
источник, разговаривает через Gemini или OpenAI в реальном времени, реагирует эмоциями
и звуковыми эффектами. Управление — из веб-панели или глобальными горячими клавишами,
удобно назначить на Stream Deck.

## Возможности

- **Говорящий аватар** — персонаж из головы и тела двигается в такт голосу. Восемь
  стилей движения: от мягкого «желейного деформера» до динамичного вращения корпусом.
- **Живые ответы ИИ** — ответ озвучивается по предложениям, пока он ещё приходит, и
  персонаж начинает говорить раньше, чем модель допишет ответ.
- **Эмоции** — модель вставляет команды `emotion(...)`, и у головы персонажа появляются
  аниме-символы (искры, «венка» злости, капля пота, тучка с дождём, пузырь мыслей…),
  а сам персонаж двигается в той же эмоции.
- **Звуковые эффекты** — команды `soundboard(...)` или кнопки в панели проигрывают
  эффект поверх речи, у каждого своя полноэкранная анимация.
- **Голос и экран** — с персонажем можно говорить через микрофон (распознавание речи в
  браузере) или показать ему снимок первого монитора.
- **Несколько ключей API** — при исчерпании квоты ключи переключаются сами, а цепочка
  запасных моделей не даёт эфиру замолчать.
- **Мастерская персонажей** — загрузите PNG, отметьте линию шеи, и картинка разделится на
  голову и тело.
- **Редактор сцены** — перетаскивайте персонажа по мини-сцене 16:9, меняйте размер,
  отражайте, настраивайте субтитры. Координаты хранятся в процентах и не зависят от
  разрешения.
- Светлая и тёмная темы.

## Что нужно

- Windows 10/11: глобальные хоткеи, запуск и снимок экрана сделаны под Windows.
- Python 3.10 или новее.
- [FFmpeg](https://ffmpeg.org/) в `PATH` — для скорости и высоты голоса.
- Google Chrome или Microsoft Edge — для распознавания речи в панели.
- Ключ Gemini API ([Google AI Studio](https://aistudio.google.com/apikey)), ключ OpenAI
  или оба.

## Быстрый старт

1. Склонируйте репозиторий.
2. Запустите **`Teekas Studio.bat`**. При первом запуске он поставит зависимости из
   `requirements.txt` и библиотеки учёта квот, затем запустит сервер и сам откроет панель управления, как
   только она будет готова. Если студия уже запущена, просто откроет панель.
3. В панели откройте **«Ключи и лимиты»** и добавьте свои ключи API.
4. Нажмите **«Призвать персонажа»** и напишите или скажите что-нибудь.

Пока идёт эфир, не закрывайте окно консоли: вместе с ним остановится сервер.

Запуск вручную:

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\.venv\Scripts\python main.py
```

| Страница | Адрес |
| --- | --- |
| Панель управления | `http://127.0.0.1:8765/control` |
| Окно для OBS | `http://127.0.0.1:8765/animation` |
| Мастерская персонажей | `http://127.0.0.1:8765/creator` |

## Настройка OBS

1. Добавьте **Браузер** (Browser Source) с адресом `http://127.0.0.1:8765/animation`.
2. Задайте размер холста, например 1920×1080. Страница прозрачная.
3. Включите **«Управлять звуком через OBS»**, если голос и эффекты должны попасть в
   микс стрима.
4. Расставьте персонажа и субтитры в разделе **«Голос и образ»** панели.

## Ключи и модели ИИ

- **Ключи** хранятся локально в `api_keys.json`. В браузер уходит только маска ключа.
  Формат — в `api_keys.example.json`. При первом запуске подхватываются ключи из
  переменных окружения `GEMINI_API_KEYS`, `GOOGLE_API_KEYS`, `GOOGLE_API_KEY`,
  `OPENAI_API_KEYS` и `OPENAI_API_KEY`.
- **Ротация.** Запросы идут по кругу.
  - После `429` от Gemini ключ отдыхает для этой модели: до полуночи по тихоокеанскому
    времени при суточной квоте, на указанный `retryDelay` при минутной и 30 минут при
    нулевой.
  - OpenAI «нет кредитов» ставит на паузу весь ключ, остальные лимиты — по
    `retry-after`.
  - Отклонённый ключ выключается, ошибки `5xx` повторяются через 2, 4 и 8 секунд.
  - Ключ меняется только до первого слова ответа.
  - Google считает квоты на проект, а не на ключ: ротация помогает только между
    разными проектами.
- **Цепочка запасных моделей** («Характер и ИИ»): каждый ответ начинается с первой
  модели. Если она недоступна на всех ключах, отвечает следующая. По умолчанию:
  `gemini-3.6-flash → gemini-3.5-flash → gemini-3.5-flash-lite → gpt-5.4 → gpt-5.4-mini`.
- **Размышления** по умолчанию выключены: тогда Flash-модели Gemini думают по минимуму,
  и первая фраза приходит примерно вдвое быстрее. Для более глубоких ответов включите
  **«Размышлять перед ответом»**.
- **Память.** Длинный разговор сжимается в сводку, обрезается или хранится целиком — по
  настройке персоны.
- **Учёт квот** (необязательно):
  [gemini_budget](https://github.com/biolog-end/gemini-budget) и
  [openai_budget](https://github.com/biolog-end/openai-budget). Лаунчер ставит их сам.
  Когда они установлены, запросы к Gemini заранее резервируются в бесплатной дневной квоте,
  запросы к OpenAI проверяются по бесплатному дневному бюджету токенов, а панель
  показывает остаток. Без них всё работает, просто без предварительной проверки.

## Эмоции и звуковые эффекты

Модель пишет команды прямо в ответе. Из озвучки они вырезаются и срабатывают в нужный
момент:

```text
emotion(surprised) Серьёзно? soundboard(vine_boom) emotion(excited) Это лучшая новость за день!
```

| Эмоция | Команда | Как выглядит |
| --- | --- | --- |
| Спокойствие | `emotion(neutral)` | мягкое оседание |
| Восторг | `emotion(excited)` | искры и прыжки |
| Веселье | `emotion(bouncy)` | ноты и пружинистое покачивание |
| Злость | `emotion(tense)` | «венка», пар, дрожь |
| Смущение | `emotion(wobbly)` | капля пота и спираль |
| Грусть | `emotion(sad)` | тучка с дождём над головой |
| Удивление | `emotion(surprised)` | рывок и большое «!» |
| Нежность | `emotion(love)` | поднимающиеся сердечки |
| Задумчивость | `emotion(thinking)` | пузырь мыслей |

Звуковые эффекты: `bad_to_the_bone`, `social_credit`, `discord_call`, `falling_pipe`,
`to_be_continued`, `vine_boom`, `answer_42`. Список — в `static/special_effects.json`.
Файлов `to-be-continued.mp3`, `vine-boom.mp3` и `42.mp3` в репозитории нет: положите в
`static/sfx/` свои с такими именами. Пока их нет, эти эффекты показывают только
анимацию. Для Falling Pipe можно положить картинки труб в `static/img/pipes/`.

Правила для модели добавляются к каждому запросу автоматически. Их можно прочитать в
**«Характер и ИИ» → «Правила эмоций и звуковых эффектов»**.

## Горячие клавиши

| Действие | По умолчанию |
| --- | --- |
| Микрофон вкл/выкл | `Ctrl+Alt+M` |
| Призвать / убрать персонажа | `Ctrl+Alt+B` |
| Отправить снимок первого монитора | `Ctrl+Alt+S` |

Меняются в разделе **«Горячие клавиши»**. Сочетание — два модификатора (Ctrl, Alt,
Shift, Win) и обычная клавиша; F-клавиши не принимаются. Хоткеи работают в любом
приложении, пока запущен сервер; вкладка панели должна оставаться открытой, но может
быть в фоне. Доступ к микрофону браузер спросит один раз.

## Настройка

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | `8765` | Порт сервера |
| `HOST` | `0.0.0.0` | Адрес; `127.0.0.1` закроет студию от локальной сети |
| `OPEN_BROWSER` | `0` | `1` — открыть панель после старта (лаунчер ставит сам) |
| `MAX_UPLOAD_MB` | `16` | Лимит загрузки в мастерской персонажей |
| `FLASK_DEBUG` | `0` | `1` включает отладчик Flask; не открывайте его в сеть |

Настройки персон хранятся в `static/personas.json`, текущая сцена OBS — в
`scene_config.json`, горячие клавиши — в `ptt_config.json`. Все эти файлы приложение
создаёт само.

## Структура проекта

```text
main.py              Flask-сервер: страницы, события аватара, синтез речи, API
key_pool.py          Ротация ключей API и обработка ошибок квот
model_fallbacks.py   Цепочка запасных моделей
gemini_chat.py       Потоковые ответы Gemini
openai_chat.py       Потоковые ответы OpenAI (Responses API)
gemini_models.py     Каталоги моделей и определение провайдера
openai_models.py
providers.py
ptt.py               Глобальные горячие клавиши
scene.py             Проверка настроек сцены OBS
static/js/           Панель, рендер для OBS (p5.js), эффекты, пластика персонажа
templates/           Панель, окно для OBS, мастерская персонажей
tests/               Тесты на Python и Node
```

## Примечания

- `api_keys.json` хранит ключи открытым текстом на вашем компьютере. Не передавайте и не
  коммитьте его.
- Звуковые эффекты в комплекте — распространённые мем-звуки, права на них принадлежат
  их владельцам.

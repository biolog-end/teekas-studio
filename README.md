# Teekas Studio

Локальный стримерский 2D-аватар с Gemini/OpenAI, потоковой озвучкой, эмоциями,
глобальными хоткеями, снимком первого монитора и учётом API-расхода.

## Запуск

Запустите `Teekas Studio.bat` (можно сделать на него ярлык). Скрипт найдёт Python
(`.venv`, если есть), при первом запуске поставит зависимости, запустит сервер и сам
откроет панель, как только она ответит. Если студия уже запущена, просто откроет
панель. Окно консоли держите открытым, пока идёт эфир. Нужен FFmpeg в `PATH`.

Вручную:

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\.venv\Scripts\python main.py
```

Панель: `http://127.0.0.1:8765/control`. Окно для OBS:
`http://127.0.0.1:8765/animation`. Порт меняется через `PORT`, `OPEN_BROWSER=1`
открывает панель после старта.

В комплекте один стартовый персонаж. Своих можно добавить в мастерской
(`/creator`): PNG с прозрачным фоном делится на голову и тело.

## Ключи, модели и лимиты

- **Ключи** — раздел «Ключи и лимиты»: сколько угодно ключей Gemini и OpenAI, подписи,
  выключение, удаление. В браузер уходит только маска ключа. Хранятся в `api_keys.json`
  (формат как в `api_keys.example.json`); ключи из `GEMINI_API_KEYS` / `GOOGLE_API_KEY(S)` /
  `OPENAI_API_KEY(S)` импортируются при первом запуске.
- **Ротация** — запросы идут по кругу. На 429 Gemini ключ отдыхает для этой модели:
  до полуночи Pacific при суточной квоте, по `retryDelay` при минутной, 30 минут при
  нулевой. У OpenAI «нет кредитов» ставит паузу на весь ключ, остальное — по
  `retry-after`. Отклонённый ключ выключается, 5xx повторяется через 2/4/8 с. Ключ
  меняется только до первого слова ответа: начатую речь не переключить.
  Квоты Google считаются на проект, а не на ключ.
- **Цепочка запасных моделей** (раздел «Характер и ИИ») — каждый ответ начинается с
  первой модели; если она недоступна на всех ключах, отвечает следующая. По умолчанию
  `gemini-3.6-flash → gemini-3.5-flash → gemini-3.5-flash-lite → gpt-5.4 → gpt-5.4-mini`.
  Бесплатные модели GPT пропускаются, если запрос не помещается в дневной бюджет.
- **Бюджеты** (необязательно) — если установлены библиотеки учёта `gemini_budget` и
  `openai_budget`, Gemini резервирует запрос через `reserve()/finish()` и показывает
  остаток бесплатных квот, а OpenAI проверяет `can_spend()` до запроса и записывает
  `record_response()` после. Без них всё работает, просто без предварительной проверки.
- **Скорость** — без «Размышлять перед ответом» Flash-модели Gemini получают
  `thinking_level=MINIMAL`: первая фраза звучит примерно вдвое быстрее.

## OpenAI budget

Каждый ответ OpenAI проходит через `openai_budget.can_spend()` и после завершения
записывается через `openai_budget.record_response()`. Статус доступен в панели и по
`GET /api/ai-budget`. Admin-ключ настраивается самой библиотекой:

```powershell
openai-budget set-key sk-admin-...
openai-budget sync
```

Без admin-ключа учитываются только запросы этого и других приложений, которые вызывают
`record_response`. Лимиты ChatGPT в браузере этот счётчик не показывает.

## Хоткеи и голос

По умолчанию: `Ctrl+Alt+M` — микрофон вкл/выкл, `Ctrl+Alt+B` — призвать/убрать аватар,
`Ctrl+Alt+S` — снимок первого монитора. Все сочетания меняются в разделе «Горячие
клавиши». Назначьте эти же сочетания кнопкам Stream Deck. Требуется минимум три
разные клавиши: два модификатора (Ctrl, Alt, Shift, Win) и обычная клавиша.
F-клавиши и повторяющиеся сочетания не принимаются; старые F8/F9/F10 автоматически
заменяются при запуске. Действие происходит при отпускании, чтобы удержание не
включало и не выключало микрофон многократно. Глобальный хук
работает, пока запущен Python-сервер; для распознавания речи вкладка панели должна
оставаться открытой и однажды получить разрешение на микрофон.

## Панель студии

- **Студия** — предпросмотр персонажа, призыв, диалог и звуковые кнопки.
- **Образ и голос** — персонаж, движение, темп, высота и субтитры.
- **Характер и ИИ** — системный промпт, цепочка моделей, размышления, память.
- **Ключи и лимиты** — ключи API и остаток бесплатных квот на сегодня.
- **Горячие клавиши** — сочетания для Stream Deck и пауза перед ответом.

Светлая и тёмная темы переключаются кнопкой в правом верхнем углу.

Настройки персоны сохраняются верхней кнопкой «Сохранить». Горячие клавиши общие
для приложения и сохраняются отдельно. В редакторе персонажей линию разреза можно
выставить кликом по PNG или ползунком. Окно OBS остаётся прозрачным, без элементов панели.

### Полноэкранная сцена OBS

Добавьте `http://127.0.0.1:8765/animation` как Browser Source размером с холст
OBS, например 1920×1080. В разделе «Образ и голос» персонажа можно перетаскивать
по мини-сцене, менять его размер и отражать. Есть быстрые позиции слева, по центру
и справа. Координаты хранятся в процентах, поэтому сохраняются при смене разрешения.

Субтитры имеют собственные координаты и ширину. Эмоции и визуальные реакции на
все кнопки soundboard рисуются отдельным полноэкранным слоем; их интенсивность и
движение самого персонажа можно отключить независимо. Команды `emotion(...)` и
`soundboard(...)` срабатывают в нужном месте потоковой реплики. Доступные эмоции:
`neutral`, `excited`, `bouncy`, `tense`, `wobbly`, `sad`, `surprised`, `love`,
`thinking`. Настройки текущей OBS-сцены сохраняются локально в `scene_config.json`.

Два основных пресета движения — «Желейный деформер» и «Динамичное вращение» —
отдельно реагируют на голос и эмоции: первый мягко сжимается и кивает, второй
поворачивается корпусом, а голова догоняет движение. При включённом системном
уменьшении анимации эта дополнительная пластика отключается.
